# Champion Master

Champion Master is a web-based management game where you manage tactics, finances, scouting, and matches. Built with HTML, CSS, and modular vanilla JavaScript.

## Features
- **Match Simulation** (`match.js`)
- **Tactics Management** (`tactics.js`)
- **Finance System** (`finance.js`)
- **Scouting System** (`scout.js`)
- **AI Opponents** (`ai.js`)

## Getting Started
Simply open `index.html` in your favorite web browser to start playing. No build step or server is strictly required, though a local web server (like Live Server) is recommended for the best experience.

## Project Structure
- `index.html`: Main entry point
- `css/`: Stylesheets for UI and mobile responsiveness
- `js/`: Core game logic and system modules
- `assets/`: Images and other static assets (if any)
